# Arcana Six

Draw six cards from the Rider-Waite-Smith deck: Major Arcana, or Minor Arcana pips (Ace to Ten, no court cards). Clear, or Cleanse the deck.

Play: https://white-hat-lab.github.io/arcana-six/

Card images: Pamela Colman Smith, 1909, public domain, via Wikimedia Commons.

Marseille deck: The Imperatrix Tarot (Web Edition), 2003, by Dominatrix / Dies Irae, distributed free for Orphalese Tarot. Used here for personal, non-commercial play.
